# Architecture Decision Records (ADR)

**Nie podjęto jeszcze żadnej decyzji architektonicznej.** Ten katalog nie zawiera zatwierdzonych ADR.

Po Technical Discovery zapisuj **istotne** decyzje w `NNNN-short-title.md`, np. gdy wybór wpływa na model danych, bezpieczeństwo, koszty operacyjne lub odwracalność rozwiązania. Mniejsze wybory kodowe nie wymagają ADR.

Minimalna treść ADR:

- Numer, tytuł i data; status `PROPOSED`, `ACCEPTED`, `SUPERSEDED`.
- Kontekst i ograniczenia wynikające z `FR/NFR/BR/OPEN`.
- Opcje i ich konsekwencje; wybrana decyzja i uzasadnienie.
- Ryzyka, skutki dla testów, plan migracji/odwrócenia i powiązania z poprzednimi ADR.
- Podmiot/źródło zatwierdzenia.

**Nie** dodawaj tu domniemanego wyboru frameworku, bazy danych, chmury lub mechanizmu AI.
